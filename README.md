
## How to use / Customise
- To change text, edit `index.html`.
- To change colors/typography, edit `css/styles.css`.
- Replace images in `assets/images/` (keep same filenames or update markup).

## Accessibility & Responsiveness
- Use semantic tags (`<header>`, `<nav>`, `<main>`, `<footer>`).
- Ensure images have alt text.
- Test keyboard navigation and color contrast.
- Mobile-first CSS and responsive breakpoints included.
